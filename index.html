About

I'm a full-stack developer focused on the .NET ecosystem — C# and ASP.NET Core on the backend, with SQL Server handling the data layer and HTML, CSS, and JavaScript on the front end. I like working with small businesses and startups because the problems are concrete: a booking system that saves someone real time, an internal tool that replaces a spreadsheet, an API a small team can build on with confidence.

My projects so far range from a quiz web application to a movie browsing site, plus a C++ game built with SFML outside the web stack. Each one taught me something different about structuring software that stays easy to maintain as it grows, which is the standard I hold my client work to as well.
